¿Qué es una Skill?

Una skill es una habilidad o capacidad específica que puede ser equipada en un agente de IA. Las skills amplían las funcionalidades del agente, permitiéndole realizar tareas especializadas como navegar sitios web, leer documentos, acceder a bases de datos, enviar emails, integrar calendarios, y mucho más.
